# T-046: Show clearly which pane is active

In a split tab it's hard to tell which pane has the keyboard, more so
with a files pane beside terminals. The active pane should stand out at a
glance (a border, a header tint, dimming the others, or similar), for
terminal and files panes alike, in every theme. Needs spec 0003 extended
first with how it looks. Asked for by the owner (2026-11-07). Area: src.
